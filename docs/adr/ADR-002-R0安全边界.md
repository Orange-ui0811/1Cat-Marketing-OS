# ADR-002：R0安全边界

状态：Accepted

- 四个平台只创建不可变人工发布任务，系统不持有平台主凭据。
- `SKL-BG-11`放在`profiles/dormant`，不得装入BGA Profile。
- PII检测失败关闭；R0无`pii_vault`表、接口或Tool。
- Agent只可调用Organization MCP白名单能力，无任意HTTP、SQL、浏览器、终端和文件写Tool。
- Run成功只形成`submitted execution evidence`，不能直接把WorkCommitment改为`fulfilled`。
- unknown结果不自动重试，创建人工对账任务。
