## 2. 权威关系

1. ORS-03 Work Commitment Ledger是组织承诺事实源；Hermes Kanban、列表、卡片和提醒只作只读投影，不允许形成第二套可写状态。
2. `AgentRun/TaskAttempt`、Tool调用、Outbox和Session是执行证据，不是组织工作语义；它们不能直接把Commitment置为`fulfilled`。
3. `ApprovalGrant`由人类身份签发；Hermes `approvals.mode`、Agent文本或管理员口吻不能产生业务授权。
4. StructuredOutputSchema定义机器可校验结构；Role Manifest和Skill定义业务语义与方法，二者都不能被另一方替代。
5. Workspace是人类协作入口，不是事实源；所有写入经OIDC身份进入ORS并执行同一状态、批准和审计合同。
6. Memory、Session、SOUL、Skill和模型输出永远不是正式业务对象、批准、承诺或审计的唯一副本。

## 3. 版本和冻结

- 合同使用独立语义版本；兼容性由`compatible_versions`显式声明，不从文件名猜测。
- 字段新增且旧消费者可忽略可作Minor；删除、改义、状态迁移变化、权限扩大或Owner变化为Major。
- 任一合同Major变化必须执行change-impact，更新Profile Bundle、UML、追踪和回归测试。
- 本目录在全部Owner签署前是冻结候选；签署时生成文件哈希清单，任一权威文件变化使原签署失效。
