## 可重复验收

创建一条新的真实 PMA Run 并完成全部联查：

```bash
.venv/Scripts/python.exe scripts/observability_acceptance.py --role pma
```

复查已有 Run，不再次调用模型：

```bash
.venv/Scripts/python.exe scripts/observability_acceptance.py \
  --run-id run_b2f5a871dcd648f7995ab0f58ff25a24
```

脚本以 JSON 输出每个检查项，并且只有全部通过才返回退出码 0。
